One transaction, or none of it.

Opening a pool for a new token by hand takes four transactions: deploy, approve, create, mint. Between any two of them the token exists with a supply and no market, which is a window somebody else can trade into, and its address has to be predicted from a nonce that anything else using the wallet invalidates. Neither problem can be fixed off-chain.

So the protocol collapses the four into one, and locks the liquidity on the way through. Three contracts, no upgrade path, no proxy.
